# Лабораторная работа №4 (ЛР03) — Вариант 7

## Задание
Ввести символ. Если символ не латинская прописная буква — сообщение об ошибке.
Иначе, если это L, M, K, D — «Это согласные буквы», иначе — «Возможно, это гласные буквы».

## Тест-кейсы
| Ввод | Результат                      |
|------|--------------------------------|
| D | Это согласные буквы            |
| A | Возможно, это гласные буквы    |
| b | Ошибка: не латинская прописная |
| 5 | Ошибка: не латинская прописная |
